# Security Policy

Report suspected vulnerabilities through GitHub's private vulnerability reporting for [`victor-software-house/open-grok`](https://github.com/victor-software-house/open-grok/security/advisories/new).

Do not open a public issue for a vulnerability or include secrets, credentials, tokens, private endpoints, or exploit details in public discussion.

`open-grok` is independent from xAI. Reports about this fork should not be sent to xAI unless the issue is independently verified to affect an official xAI product.
