# Changelog

All notable changes to `open-grok` are recorded here.

This project follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and will use [Semantic Versioning](https://semver.org/) for independent `open-grok` releases. Upstream imports retain their own immutable source revisions and are documented separately under [`docs/upstream/`](docs/upstream/).

## [Unreleased]

### Added

- Added a source-pinned architecture dossier covering runtime ownership, providers and authentication, persistence, the complete tool lifecycle, extensions, workspace topology, reference patterns, and documentation gaps.

### Changed

- Integrated xAI snapshot [`c68e39f`](https://github.com/xai-org/grok-build/tree/c68e39f60462f28d9be5e683d9cbe2c57b1a5027) through isolated synchronization PR #2, preserving fork history and importing its Pager navigation, session/runtime, permission, authentication, sandbox, workspace, and expanded PTY coverage changes.
